# GRILLAD gateway candidate (not deployed)
Reuse famille-account-lifecycle login/recovery and caller-token RPCs. Requires 0004 account/session binding, matching active membership and device, explicit GRILLAD enabled site, exact subscription, reviewed provisioning, and approved deployment. Set exact GRILLAD_ALLOWED_ORIGINS; no wildcard. Public anon/publishable key only on clients. Because login/recovery and refresh occur before a user JWT exists, configure gateway JWT verification off **only for this function** after review; RPC enforces caller auth and all scope checks; no service role in this gateway. Do not expose famille_private or grillad_private. Do not deploy until local GoTrue and device revocation recipes pass. No automatic password-change workaround.
