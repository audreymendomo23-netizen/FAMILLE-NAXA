# WideMeet — Photographies de design

Déposer ici les fichiers originaux destinés aux interfaces WideMeet (JPG, PNG, WebP ou AVIF). Conserver la résolution et la qualité d'origine, sans flou ni recompression destructive. Les noms descriptifs facilitent le choix des photos par page.

Les photos seront sélectionnées et intégrées au Web/PWA et à Android, avec animations fluides et respect du réglage de réduction des mouvements. Les originaux restent inchangés. Ne déposer que des images autorisées à être publiées : le dépôt GitHub est public. Aucun secret ni photo personnelle confidentielle.
