# Famille NAXA

Monorepo de référence pour les dix applications autonomes : Kiosko, Bootik, Zipple, NAXA Services, CotiZ, Loyable, NAXA Hotel, Campus237, NAXA Security et GrillaD.

- Android : APK autonomes distribuées depuis le site NAXA ; pas de Play Store.
- Web responsive/PWA selon le périmètre de chaque application.
- Backend Supabase NAXA partagé après audit de compatibilité et sans duplication inutile.
- Aucun secret dans ce dépôt public.
- Aucune migration Production, aucun déploiement et aucune publication APK sans autorisation explicite.

Lire [AGENTS.md](AGENTS.md), [Architecture](docs/ARCHITECTURE_CIBLE.md) et [Continuité](docs/CONTINUITE.md).
