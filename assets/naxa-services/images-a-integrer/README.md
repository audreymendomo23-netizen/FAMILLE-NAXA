# Images à intégrer — NAXA SERVICES

Déposer ici les images destinées à l'application Android, Web et PWA : arrière-plans, écrans de démarrage, illustrations des activités et autres visuels.

- Privilégier les originaux HD (JPG, PNG ou WebP), sans compression préalable excessive.
- Nommer les fichiers selon leur usage : `accueil.jpg`, `connexion.jpg`, `pressing-01.jpg`, `coiffure-01.jpg`, etc.
- Déposer uniquement des visuels autorisés pour l'usage commercial, sans données personnelles ni secrets.
- Les images de ce dossier constituent une réserve de travail : leur dépôt ne modifie pas automatiquement les écrans. Sélection, optimisation et intégration seront effectuées séparément.
