# NAXA SERVICES — Activity photo library

This directory contains one folder per activity profile. Add 6 to 10 approved photos to each activity folder when ready.

## Naming and technical guidance
- Use 01-cover.webp for the main activity image.
- Add 02-workspace.webp through 10-detail.webp for supporting images.
- Prefer WebP or optimized JPEG, landscape 16:9 for dashboard cards, crop-safe central subjects, and 1200 px maximum long edge.
- Keep each image reasonably compressed (target under 250 KB where image quality permits).
- Do not commit customer faces, invoices, phone numbers, private locations or unlicensed stock imagery.
- Provide usage rights or source information alongside photos when they are not original assets.
- The app will load only the selected activity's images and use a readable dark overlay; no image is required for operation.

Folders: pressing, coiffure, couture, beaute, parfumerie, reparation, menuiserie, garage, nettoyage, domicile, impression, photo_evenementiel, autre.
