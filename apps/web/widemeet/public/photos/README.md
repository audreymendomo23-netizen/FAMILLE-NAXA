# Photos originales WideMeet

Déposer ici les visuels destinés aux interfaces WideMeet (JPG, PNG, WebP, AVIF). Conserver les fichiers originaux, sans flou, compression destructrice ni réduction de résolution. Utiliser uniquement des images autorisées à la publication : ce dépôt et ce répertoire Web sont publics. Préférer des noms descriptifs. Les animations UI devront respecter prefers-reduced-motion et ne pas dégrader les visuels.
